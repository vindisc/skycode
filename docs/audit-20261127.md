## 查出但本轮有意不修（留档）

1. **BridgeJwtManager**：刷新重试在唯一调度线程上 sleep 最多 3 分钟阻塞其他会话；cancel/schedule 有代际复活竞态。需要按会话锁/状态机收敛的重构，改动面大，建议单独一轮做。
2. **ToolResultSummarizer 的 LLM 摘要链**生产不可达（同上，牵动构造器与 Mock）。
3. **activityStore.performRetention** 是死代码，Activities Map（含 diff 全文）单会话内无限增长；processed Set 与 denied/approvedToolUseIds 只增不减。接线涉及 APOS 数据流的产品决策（保留多少、何时清），建议与产品对齐后再动。
4. **HTTP journey 的步内绝对 URL（SSRF 面）与 workspace TOCTOU 窗口**：属于「设计使然 + opt-in 场景」，修复需要白名单/目标网段策略的产品决策。
5. **前端 41 个 `it.skip` 空壳 + 后端 43 个 `@Disabled` TODO 占位**：是欠账清单而非过时测试，批量补齐超出本轮范围。
6. **测试覆盖大缺口**（本轮只补了与修复直接相关的部分）：后端 controller 层 17 个无专属测试（AuthController、MCP 三控制器等）、QueryEngine 等引擎核心仅集成测试间接覆盖；前端 49 个 store 中 33 个无测试；Python 仅 `code_intel.py`、`tokenizer.py` 无专属测试（后者本轮已随修复带上兜底断言）。
7. **架构性观察**（未动）：`WebSocketController`（2173 行）与 `QueryEngine`（3007 行）两个上帝类；会话「谁在运行」的真相分散在 abortContexts / RunExecutionRegistry / WebSocketSessionManager 三套机制里，交界处最容易引入映射漂移，值得加集成测试保护。
8. `build-king-video-previews.sh` 注释里的「就近归并 8/10→sm」一行注释也漂移了（实际 sm=8、md=10），与圆角令牌注释同源，未随本轮修改。
9. e2e 修复只做了代码对照（本机没有 Playwright 浏览器，无法实际跑通验证）。
